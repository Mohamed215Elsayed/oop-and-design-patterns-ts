# SOLID Principles

بعد الحديث عن المبادئ الأولية لتصميم أي شيفرة برمجية، نستعرض الآن خمسة مبادئ أخرى ستجعل الكود:
- أكثر **مرونة**
- أكثر **وضوحًا** وسهولة فهم
- أسهل في **الصيانة والتعديل**
- قادر على **التوسع** دون أن يسبب تغيّر حجم المشروع مشاكل كبيرة

هذه المبادئ صاغها **Robert C. Martin** في كتابه *Agile Software Development, Principles, Patterns, and Practices*، واسم **SOLID** هو اختصار للحروف الأولى من خمسة مبادئ في الـ OOD (Object-Oriented Design):

| Letter | Principle | المبدأ |
|---|---|---|
| **S** | Single-Responsibility Principle | مبدأ المسؤولية الواحدة |
| **O** | Open-Closed Principle | مبدأ الفتح والإغلاق |
| **L** | Liskov Substitution Principle | مبدأ استبدال ليسكوف |
| **I** | Interface Segregation Principle | مبدأ فصل الواجهات |
| **D** | Dependency Inversion Principle | مبدأ عكس الاعتمادية |
